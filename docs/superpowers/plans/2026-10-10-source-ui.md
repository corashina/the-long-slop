**Goal:** Match source menus, contextual feedback, supported controls, fluid text, and Lada instruments in My Summer Slop.

**Architecture:** Extend the existing validated export. Rust owns available actions and instrument signals. Browser modules own menus, input, and feedback.

**Tech Stack:** Rust, WebAssembly, Bevy 0.19.1, Rapier 0.36.0, serde, UnityPy, Pillow, HTML/CSS, and JavaScript.

**Spec:** [Approved source UI design](../specs/2026-10-10-source-ui-design.md).

## Review Focus

1. Capture resolves after focus loss: the game must remain paused and reject the stale capture result. Task 3 tests this.
2. Pickup and release occur before one physics step: one F gesture must not pick up and remount an item. Task 2 tests this.
3. Missing sprite or instrument link: loading must fail by name and keep Start disabled. Tasks 1 and 3 test this.
4. Container changes without changing volume: feedback must use the new capacity and name without stale text. Task 4 tests this.
5. Recovery or origin rebase changes parent poses: instruments must keep their relative rotation and odometer value. Task 5 tests this.
